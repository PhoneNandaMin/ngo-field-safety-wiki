About this demo

What you're looking at, and what's different in a real deployment.

What this is

Every page you just clicked through is a separate, plain HTML file with one shared stylesheet. There is no database, no build step, and no JavaScript. That's deliberate — it's the same reason these pages loaded instantly: there is almost nothing for a slow connection to wait on, which matters when the person reading it may be on 2G in the field.

What changes with a real wiki engine (DokuWiki)

  • Real search — searches inside page text, not just titles like the "All entries" page here.
  • Editing without touching files — your team edits through a web form; DokuWiki writes the page file for you.
  • Login-gated editing — an actual "Edit" button appears only for logged-in team accounts; the public never sees one.
  • Page history — every edit is kept, so you can see who changed what and revert if needed.

What stays the same

The page structure, the category/entry layout, the cross-linking between related entries, and the low-bandwidth loading — all of that carries over directly. This demo is the actual shape of the final site, just without the editing backend wired up yet.

This is a structural demo, not final content — placeholder entries only, not verified guidance.
